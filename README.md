# Telegram-бот Yubara «Юбара»

## Mini App

Mini App теперь сфокусирован на мини-играх: карточных комнатах для подкидного
дурака на 2–4 игроков, ежедневном раскладе Таро с кратким толкованием от ИИ и
колесе удачи. Профиль, площадка, сообщество, активация и инструменты
администратора доступны через прежние сценарии бота, но не отображаются в
игровом Mini App. Правила и технические ограничения описаны в
[MINIAPP_PROGRESS.md](./MINIAPP_PROGRESS.md).

Бот запускается в режиме polling и использует SQLite, Groq и HTTP healthcheck,
который Render проверяет на порту `PORT`.

## Команды Telegram и меню BotFather

Кнопка **🔑 Активировать код** есть в главном меню. Нажми её и отправь ключ,
монетный промокод или штрафной код следующим сообщением — вводить `/activate`
не нужно. Пользователь без доступа к ЛС тоже получит эту кнопку в ответе бота.
Команды активации ниже остаются доступными как альтернативный способ.
Баннерский ключ также активируется этой кнопкой; он выдаёт отдельную копию
сохранённого шаблона и не меняет исходный баннер.

Для добавления списка в BotFather отправь `/setcommands`, выбери нужную область
команд и вставь строки из блока (без символа `/`). Команды BotFather только
показываются в меню Telegram; доступ всё равно проверяет сам бот. Основной
список предназначен обычным пользователям. Администраторы бота получают его
плюс команды из соответствующего дополнительного блока.

**Основные команды пользователей:**

```text
start - Начать работу или показать доступные кнопки
help - Справка с учетом ваших прав
adminhelp - Справка с учетом ваших прав
helpadmin - Алиас команды help
fortuna - Открыть колесо удачи
casino - Алиас команды fortuna
slots - Алиас команды fortuna
inventory - Открыть инвентарь баннеров
inv - Алиас команды inventory
banner - Показать активный баннер
market - Открыть площадку
activate - Активировать ключ или код
coinpromo - Активировать промокод на монеты
profile - Открыть профиль
top - Рейтинг сообщений в группе
recycle - Переработать баннеры по редкости и количеству
image - Создать изображение по описанию
img - Алиас команды image
reaction - Поставить случайную реакцию
react - Алиас команды reaction
forget_me - Удалить сохраненные данные о себе в этой группе
cancel - Отменить текущий ввод или диалог
```

Аргументы и варианты: `/start inventory` или `/start casino`; `/market запрос`;
`/casino` и `/slots` остаются алиасами `/fortuna`;
`/activate КОД` и `/coinpromo КОД`; `/top d`, `/top n`, `/top m`;
`/recycle редкость количество` (например, `/recycle редкий 3`);
`/image описание`. `/profile ID` в группе открывает профиль группы по ID.
`/forget_me` работает в группах.

**Дополнительные команды администратора группы:**

```text
activategroup - Подключить группу одноразовым кодом
```

Использование: `/activategroup YUBARA-...`. Код может применить администратор
этой группы или администратор бота. Команды удаления сообщений доступны
администраторам группы и бота как текст: ответь `дэл` на сообщение, чтобы
удалить его; `дэл N` (ответом на сообщение Юбары) удаляет последние N сообщений
Юбары; `дэл чат N` удаляет последние N сообщений чата.

В панели `/adm` → **Доступ и ключи** администратор может создать баннерский
ключ, отправив три значения через пробел, например `123456 5 123456789`.
Используй шестизначный номер, напечатанный на самом баннере.
Бот сверит номер, уровень и владельца, затем создаст одноразовый ключ
`YUBARA-BANNER-...`. Ключ активируется
в личном чате кнопкой **🔑 Активировать код**; получатель получит новый предмет
с прежним seed и пресетом, но со своим именем и аватаром. Исходный баннер не
изменяется. Если номер совпадает у нескольких шаблонов, вместо номера укажи
`id:ITEM_ID` из подписи резервного сообщения. Неиспользованный ключ можно
отозвать из той же административной панели.
Кнопка **🎨 Обновить баннер под профиль** меняет имя и аватар владельца, но
сохраняет seed, пресет и дизайн баннера.

**Дополнительные команды администратора бота:**

```text
adm - Открыть панель администратора
addacc - Подключить и настроить личный Telegram-аккаунт
gethistori - Выбрать группу и получить файл истории
fees - Показать накопленную комиссию площадки
testbanner - Сгенерировать тестовый баннер
break - Штатно остановить процесс бота
deletealldata - Запросить полный сброс данных
resetall - Алиас команды deletealldata
cancel - Отменить текущий ввод или диалог
```

`/addacc` также доступна пользователям с отдельным доступом к автоответчику.
`/gethistori` требует членства и прав администратора в выбранной группе.
`/deletealldata` и `/resetall` доступны только владельцу бота и требуют
подтверждения; действие необратимо.

Для баннеров и рейтингов в `yubari_banner/fonts/` включены DejaVuSans и
лицензированные Noto Fonts: Symbols 2, Color Emoji, Math, Japanese, Tibetan,
Egyptian Hieroglyphs, Old Italic, Gothic, Kannada, Khmer, Tagalog и Tifinagh.
Они нужны для отображения Unicode-имён и символов; лицензии шрифтов находятся
рядом с файлами.

## Локальный запуск

1. Установите Python 3.11.
2. Создайте виртуальное окружение и установите зависимости:
   `pip install -r requirements.txt`
3. Скопируйте `.env.example` в `.env` и заполните переменные.
4. Запустите `python main.py`.

## Деплой на Render

Создайте **Web Service**, подключите репозиторий и укажите:

- Build Command: `pip install -r requirements.txt`
- Start Command: `python main.py` (команда Procfile: `web: python main.py`)
- Корневой `.python-version` закрепляет Python `3.11.11` для Render.

Если в настройках Environment сервиса задан `PYTHON_VERSION`, он может
переопределять версию из `.python-version`; укажите там `3.11.11` или удалите
это переопределение, затем запустите новый Deploy. Приложение также явно
создаёт asyncio event loop перед запуском polling для совместимости с
средами Python, в которых loop больше не создаётся автоматически.

В Environment добавьте `TELEGRAM_TOKEN`, `GROQ_API_KEY`, `HISTORY_ENCRYPTION_KEY`
и `ADMIN_ID`. Каналы `BACKUP_CHANNEL_ID` и `LOGS_CHAT` необязательны: без них бот
запустится и будет работать, но резервные копии и пересылка логов в Telegram
будут отключены. Для саммари можно задать `GEMINI_API_KEY` из Google AI Studio.
Сначала бот попробует модели из `SUMMARY_GEMINI_MODELS`, затем модели Groq из
`SUMMARY_GROQ_MODELS`; по умолчанию это `gemini-2.5-flash`,
`gemini-2.0-flash`, а затем `openai/gpt-oss-120b`, `llama-3.3-70b-versatile`
и `llama-3.1-8b-instant`. Списки задаются через запятую и могут быть изменены
в Environment; доступность моделей и лимиты зависят от ключа и провайдера.
Если Gemini не настроен или все модели недоступны, бот всё равно попробует Groq.
`HISTORY_ENCRYPTION_KEY` — постоянный ключ Fernet, необходимый для шифрования
истории в SQLite, DB-бэкапах и зашифрованных файлах истории в Telegram. Создайте его
один раз командой `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`
и сохраните в секретах Environment. Не меняйте и не теряйте ключ: без него ранее
сохранённую историю нельзя расшифровать. При первом запуске незашифрованные записи
SQLite автоматически шифруются и помечаются для обновления DB-бэкапа.
`BACKUP_CHANNEL_ID` используется для резервных копий базы данных и файлов
Telegram-сессий, а операционные предупреждения и события
отправляются отдельно в `LOGS_CHAT`. Render задаёт `PORT` для Web Service автоматически;
локально бот использует `8080`, если `PORT` не задан.
HTTP-сервер отдаёт главную страницу Mini App по `/` и `/index.html`, а `/health`
используется для проверки состояния. Статические стили, SVG-символы и JavaScript
модули находятся в `webapp/` и отдаются только из разрешённого списка ресурсов.
После Deploy укажите HTTPS-адрес сервиса в настройках Mini App через BotFather.
Mini App проверяет подписанные Telegram данные запуска на сервере. В первой
версии доступны профиль, колесо удачи с крутками ×1 и ×10, покупка и продажа
баннеров на площадке, передача баннеров с подтверждением получателя,
активация ключей/промокодов и админ-управление доступом.
Администраторские API
повторно проверяют права на сервере; скрытие раздела в интерфейсе не является
проверкой доступа. Команды и кнопки бота продолжают работать независимо от Mini App.
После покупки или активации баннер появляется в инвентаре бота; открыть его можно
командой `/inventory`. В профиле Mini App инвентарь показан каруселью; баннер
можно активировать, переработать или передать пользователю, известному боту.
Получатель должен подтвердить передачу; отправитель может
отменить запрос, а получатель — принять или вернуть его в Mini App либо
воспользоваться сообщением бота. Фото открытых лотов и ожидающих передач берутся
по сохранённым ссылкам и проксируются сервером без выдачи токена бота. Если
у старого баннера ещё нет сохранённого превью, бот восстановит его из резервного
канала или подготовит при первом открытии изображения.
Bot API не позволяет перечислять историю канала, поэтому Mini App показывает
изображения баннеров, уже записанные в базе, а не импортирует неизвестные
сообщения из архива. Шансы и правила колеса общие с ботом, а результаты
фиксируются в базе до анимации. В разделе «Сообщество» доступны рейтинги
сообщений и монет для подключённых групп, отправка сообщения об ошибке,
удаление сохранённых профильных данных и отправка запроса на генерацию
изображения. Генерация продолжает работу в личном чате бота, где доступны
настройки и запуск; бот должен быть предварительно открыт пользователем.
Операции с сообщениями и администрированием групп, дуэли с другими участниками,
автоответчик, подключение личного Telegram-аккаунта и полная история чата
остаются в боте: Mini App не может выполнять действия от имени пользователя
или подменять контекст конкретного сообщения/группы. Управление группами,
выпуск баннерских ключей, остановка сервиса и полный сброс данных остаются
в админ-диалогах: эти действия требуют подтверждений или секретов, которые не
следует переносить в веб-формы.
Удаление профильных данных в Mini App действует на все группы и удаляет
сохранённые имя, кличку, возраст, пол, факты и статистику сообщений; оно не
удаляет архивированные сообщения и не затрагивает баланс, баннеры и игровые покупки.
В профиле Mini App также можно обновить кличку, возраст, пол и добавить факт.
Текущий этап и дальнейшие
ограничения описаны в `MINIAPP_PROGRESS.md`.
В журнал приложения выводятся дата и время, уровень, модуль и сообщение
в формате `YYYY-MM-DD HH:MM:SS | ERROR | logger | сообщение`; исключения
содержат traceback. Предупреждения и ошибки дополнительно пересылаются в `LOGS_CHAT`.

В личном чате с ботом `/gethistori` показывает группы, в которых запрашивающий
состоит и является администратором группы либо администратором бота. Проверка
членства повторяется после выбора группы; история отправляется отдельным `.txt`
файлом с полями «время | имя | пол | возраст | текст | реакции и от кого |
reply-to». В Telegram-бэкап загружается только зашифрованный файл `.txt.enc`.
При вступлении участнику предлагается добровольно выбрать пол и возраст; оба
вопроса можно пропустить. Команды удаления сообщений доступны администраторам
группы или администраторам бота, выполняются без сообщений-подтверждений;
`дэл чат <число>` удаляет указанное количество последних сообщений без reply-to.
Команды `/help`, `/adminhelp` и `/helpadmin` показывают общие команды и
отдельные разделы для администратора группы и администратора бота, если у
пользователя есть соответствующие права.
Баннеры профиля строятся из `yubari_banner`: уровни 1–5 — PNG, легендарный
уровень 6 — GIF. На баннере показывается сохранённая кличка, без `@username`.
В ЛС и группах профиль содержит имя, username, возраст, пол, факты и статистику
сообщений D/W/M; факты показаны сворачиваемой цитатой. В списке участников
группы эти сведения также отображаются полностью.
Под карточкой доступны инвентарь, изменение клички и добавление фактов;
кличку также можно указать фразой «меня зовут …». Коллекционные баннеры,
активный выбор и ссылки на файлы хранятся в SQLite; готовые изображения сразу
загружаются в `BACKUP_CHANNEL_ID`, поэтому после редеплоя они выдаются по
Telegram `file_id`, без постоянного хранения картинок на сервере.
Кнопки D/W/M под групповым профилем переключают статистику в той же карточке;
изменение видно всем участникам группы.
Кнопки `D | W | M` показывают число сообщений пользователя во всех подключённых
группах за текущий день, неделю (с понедельника) или календарный месяц по Москве.
Команда `/top` в группе выводит баннер активности за день; `/top n` (также
`/top w`) и `/top m` — за неделю и месяц. В сообщении есть кнопки переключения
периода и перехода к рейтингу монет. Текстовые запросы «топ активности» и
«статистика активности» также показывают рейтинг; поддерживаются периоды Д/Н/М.
Статистика хранится отдельно от ограниченной истории чата, а при первом запуске
доступные записи за текущий месяц переносятся в счётчики.

До 16 обновлений Telegram могут обрабатываться одновременно; обновления одного
пользователя по-прежнему выполняются последовательно, чтобы не ломать анкеты,
игровые действия и диалоги. Поэтому долгий ответ одному пользователю не должен
останавливать работу бота для остальных.

«Колесо удачи» открывается командой `/fortuna` (также работают прежние
`/casino` и `/slots`) или текстом «казино» либо
«колесо удачи» в группе с Юбарой
и в ЛС; инвентарь доступен по `/inventory` или «инвентарь» (в группе бот даст
ссылку в ЛС). Инвентарь можно просматривать каруселью с зацикленными стрелками
или списком; фильтр по редкости и сортировка по дате/уровню доступны в обоих режимах.
В ЛС меню и разделы открываются inline-кнопками под сообщениями.
Крутка стоит 2 монеты, ×10 доступна в ЛС; анимация десяти бросков показывается
группами по три кубика, все кубики удаляются после завершения анимации, а каждый
выигранный баннер отправляется отдельным сообщением. Результаты задают значения
кубиков Telegram. Инвентарь и торговая площадка показывают по одному баннеру за
раз со стрелочной навигацией.
Предметы можно выбрать активными, переработать по отдельности или командой
`переработка <редкость> <количество>` (например, `переработка редкий 3`, максимум
30 свободных баннеров одного уровня за вызов), либо выставить на площадку;
при выставлении можно задать название лота. В площадке кнопка поиска или команда
`/market <запрос>` ищет приблизительно по названию лота, редкости, цене и
паттерну; слова запроса можно расположить в любом порядке, например
`розовый элитный`, `элитный розовый`, название паттерна или `12.50`. В карточке
лота показываются название, редкость, паттерн и цена; имя продавца не раскрывается.
Продажи начисляют продавцу 80% цены, а комиссию можно посмотреть командой
`/fees` администратору бота. Кнопка «В меню» возвращает в главное меню.
Ключ доступа можно активировать кнопкой «🔑 Активировать код» в меню, отправив
код следующим сообщением; альтернативно работают `/activate КОД` и обычный ввод
ключа без команды. Администратор бота может
создать промокод на монеты в `/adm` → «Доступ и ключи»
→ «Промокод на монеты», указав сумму от 0.01 до 100000 монет. Код одноразовый:
его активирует один пользователь кнопкой в меню, `/coinpromo YUBARA-COIN-...`
или `/activate YUBARA-COIN-...` в ЛС с ботом. Передавай код получателю лично —
тот, кто первым его введёт, получит монеты; для активации не обязательно иметь
доступ к обычному диалогу.
В том же разделе можно выпустить одноразовый штрафной ключ с положительной
суммой: пользователь активирует его кнопкой меню или командой
`/activate YUBARA-PEN-...`, после чего сумма списывается с его баланса. Баланс
может стать отрицательным. Неиспользованные штрафные ключи можно отозвать в
админ-панели.
Баннер можно передать другому пользователю из инвентаря кнопкой
«Передать». Получатель указывается как `@username` или Telegram ID и должен
хотя бы раз взаимодействовать с Юбарой. Запрос не меняет владельца до решения
получателя: кнопка «Принять» завершает передачу, а «Вернуть» отменяет запрос и
оставляет баннер у отправителя. Обе кнопки доступны в ЛС и в подключённых
группах, где Юбара подтверждает членство получателя. Отправитель может отменить
ожидающий запрос из инвентаря. При принятии переданный баннер становится активным
у получателя вместо его прежнего активного баннера. Сам файл при передаче
сохраняется без изменений; кнопка перерисовки в профиле создаёт дизайн с аватаром
получателя. Для уже принятых ранее передач кнопка профиля также подхватит последний
полученный неактивный баннер, если активного баннера нет. Служебный или выставленный
на площадку баннер передать нельзя.
В справке есть кнопка «Сообщить об ошибке»: она отправляет владельцу бота
текстовое обращение длиной до 3000 символов.
Администратор может сгенерировать пробный баннер командой `/testbanner` в ЛС.
Уровень и паттерн можно указать явно, например `/testbanner 6 starry`; предмет
в инвентарь при этом не добавляется.

Бонус за подписку проверяется для `@megurushka`; чтобы проверка и штраф при
отписке работали надёжно, добавьте бота администратором канала с правом видеть
участников. События `chat_member` используются сразу, а резервная проверка
выполняется периодически. Отрицательный баланс показывает служебный баннер и
временно запрещает выставлять лоты; баннеры остаются в инвентаре.
Владелец бота может выполнить `/deletealldata` в личном чате и подтвердить
полный сброс: удалятся все строки данных SQLite, локальные архивы и сессии, а
также известные боту документы резервных копий и баннеры в `BACKUP_CHANNEL_ID`.
При ошибке удаления документов сброс базы не выполняется. Операция необратима.

Для подключения личного Telegram-аккаунта администратора в `/adm` дополнительно задайте
`TELEGRAM_API_ID` и `TELEGRAM_API_HASH` из `my.telegram.org`. На Render создайте
persistent disk и задайте `TELEGRAM_USER_SESSION_PATH`, например
`/var/data/telegram_user.session`, где `/var/data` — точка монтирования диска.
Файл сессии даёт полный доступ к аккаунту: не публикуйте его и не добавляйте
в Git. Перед подключением меню предупреждает, что файл будет храниться
в `BACKUP_CHANNEL_ID`; этот канал должен быть приватным и доступным только
доверенным администраторам.
Номер телефона, код входа и пароль 2FA отправляются администратором в личный чат
с ботом; бот удаляет эти сообщения до передачи данных авторизации Telegram.
В `/adm` → «Личный Telegram-аккаунт» → «Войти по QR-коду» бот отправит QR
в личный чат; сканировать его нужно с другого уже авторизованного устройства
через Telegram → Настройки → Устройства → Подключить устройство. QR обновляется
автоматически при истечении срока и удаляется после входа, если Telegram это
позволяет. QR является временным токеном входа — не пересылайте его.
При входе по номеру Telegram сообщает способ доставки кода: часто код приходит
в официальный чат Telegram на другом уже авторизованном устройстве, а не по SMS.

## Доступ и изображения

В `/adm` можно создавать одноразовые ключи обычного доступа, приглашения
администраторов и отдельные ключи автоответчика, выбирая срок: навсегда, 30 дней, 7 дней или 24 часа
(срок отсчитывается с активации ключа). Существующие пользователи при
обновлении остаются бессрочными. У администраторов полный доступ к панели;
кнопки в панели позволяют отзывать ключи, пользовательский доступ и права
дополнительных администраторов. Главный `ADMIN_ID` не отзывается.
Главное меню `/adm` разделено на разделы «Управление группами» и
«Доступ и ключи»; личный аккаунт и автоответчик вынесены в отдельные пункты.
Переключатель контекста доступен прямо на главном экране.
Для обычного использования группы промокод больше не нужен: когда Юбара есть
в группе, участники могут обращаться к ней напрямую. Группа автоматически
регистрируется при первом сообщении, которое получает бот; промокод
`/activategroup YUBARA-...` из `/adm` остаётся дополнительным способом
подключения группы заранее. Команда с префиксом `/` работает даже если у бота
включён privacy mode.
Участнику группы также доступен бот в ЛС. Первый раз нужно написать Юбаре
в группе, чтобы она запомнила членство. При каждом обращении в ЛС членство
проверяется через Telegram; если пользователь вышел из всех групп с Юбарой,
доступ в ЛС закрывается. Чтобы Telegram надёжно сообщал о вступлении и выходе,
добавьте бота администратором в группы. Если человек остаётся участником хотя
бы одной группы с ботом, доступ в ЛС сохраняется.
Пользователь активирует ключ автоответчика сообщением боту, затем открывает
`/addacc`: там он подключает собственный Telegram-аккаунт и отдельно настраивает
режимы, часовой пояс, группы и текст. Сессия пользователя хранится отдельно
от сессии администратора в каталоге `<TELEGRAM_USER_SESSION_PATH>.accounts`.
Меню `/addacc` группирует подключение, режимы, параметры рассылки и редактирование
текстов; текущие статусы режимов и часовой пояс видны сразу на главном экране.
Ключ автоответчика не открывает обычный диалог с ботом.
В `/adm` доступны настройки автоответчика: выбор часового пояса UTC−12…UTC+14
(по умолчанию Москва, UTC+3), а также отдельные переключатели ночной рассылки и
автоответа в личных сообщениях. Эти настройки и выбор групп сохраняются в SQLite.
Для ночной рассылки выбери группы в разделе «Группы ночной рассылки»: список
включает только группы из белого списка, в которых состоят и подключённый
личный аккаунт, и бот Юбара. С 23:30 до 03:00 выбранного часового пояса
проверяются раз в минуту сообщения личного аккаунта, отправленные с 21:00.
Если последнее
исходящее сообщение аккаунта отправлено не более 45 минут назад, рассылка
пропускается. Иначе Groq проверяет вечерние сообщения аккаунта;
если явного пожелания спокойной ночи не было, аккаунт отправляет пожелание
один раз за вечер. Сообщения других участников при проверке игнорируются.
Для редактирования текста открой `/adm` → настройки автоответчика либо
`/addacc` и выбери текст ночного пожелания или текст автоответа в ЛС. Тексты
ограничены 1000 символами; фрагменты в круглых скобках вместе со скобками
отображаются как spoiler (пример: `Всем сладких снов! (увидимся завтра)`).
Текст автоответа и текст ночного пожелания сохраняются отдельно для каждого
пользователя.
Включённый автоответ в личных чатах отвечает на входящее сообщение, только если
аккаунт не отправлял сообщений ни в одном чате Telegram в течение последних
15 минут. Если аккаунт писал кому-либо в Telegram за это время, автоответ не
отправляется. Сам автоответ также считается исходящим сообщением. Текст в
скобках в обоих сообщениях отправляется
как скрываемый Telegram spoiler. Для работы режимов user-аккаунт должен быть
подключён и включён в `/adm` либо в персональном меню `/addacc`.
Администратор может отправить `/break` в личном чате с ботом для штатной
остановки текущего процесса, включая финальную остановку задач и резервное
копирование. Render может автоматически перезапустить остановленный сервис.

Юбара использует последние 5 сообщений группы как контекст ответа; история
личных сообщений с ботом не сохраняется и прежние записи личных чатов удаляются
при запуске. Часовые метки, ежедневные расчёты и дата для ответов используют
московское время (UTC+3). В контекст каждого ответа передаются текущие дата и
время по Москве.
В админ-панели `/adm` можно глобально включить или отключить использование
истории групповых чатов. При выключенном контексте учитываются только текущее сообщение
и сообщение, на которое пользователь ответил. Подробные пересказы используют всю доступную историю за выбранный период,
максимум 24 часа (по умолчанию 12 часов), если контекст включён.
В обычном разговоре она отвечает по делу и обычно кратко, но может дать
развёрнутое объяснение, когда этого требует вопрос. Саммари в группах можно
запросить за указанный период, например «саммари за 3 часа» или «за день»;
период ограничен 24 часами, а без указания периода берутся последние 12 часов.
В разрешённых группах
приветствует новых участников и иногда ставит реакцию на сообщение, на которое
ответила.
На вопрос «что ты знаешь обо мне?» Юбара выдаёт профиль по сохранённым сведениям
текущего чата, не смешивая данные участников из других групп. На запросы вроде
«что ты знаешь о группе?» или «расскажи о нас» она перечисляет известные факты
об участниках; профиль формируется по сохранённым данным, а не только по ответу
языковой модели.
Профиль пользователя и его монеты общие для всех чатов. В профиле показываются
имя, username, кличка, возраст, пол и заметки; ID пользователей и групп
в сообщении профиля не выводятся. Баннер профиля подписан сохранённой кличкой
(или именем, если кличка не задана), поэтому обновляется при смене клички.
Легендарные баннеры анимированные. Уникальная декорация сохраняется в резервной
копии по ID пользователя.
Если участник прямо сообщает свой возраст, например «мне 25 лет», он сохраняется
в профиле; проверить сохранённые сведения можно командой `/profile`.
В группе можно запросить `/profile` для себя, `/profile -1001234567890` для
профилей участников разрешённой группы или сказать «профиль группы ID».
Существующие групповые заметки переносятся в единый профиль при обновлении.

Вызовите её, например, фразой «Юбара, я вызываю тебя на батл», чтобы сыграть
в кости. Бот ждёт завершения анимации каждого броска, прежде чем продолжить.
Чтобы вызвать другого участника, ответьте на его сообщение или упомяните его
в сообщении со словом «батл». Соперник может принять вызов или отказаться
кнопкой в течение двух минут; против Юбары батл начинается сразу.
Новый игрок начинает с 5 монет; победа даёт 2, поражение отнимает 1,
при ничьей баланс не меняется. Счёт хранится глобально по Telegram ID пользователя;
текущий счёт можно узнать словом «баланс», а запрос «топ монет» работает только
в группах. В рейтинге монет учитываются только участники текущей группы; их
кошелёк остаётся общим между чатами. Для топ-3 в баннерах предусмотрены золотая,
красная и бело-розовая короны, остальные участники размещаются на башнях ниже.
Команды удаления доступны только администраторам группы или администраторам бота
и выполняются без сообщений-подтверждений. Команда «дэл чат 3» удаляет три
последних сообщения чата без reply-to.
Если личный Telegram-аккаунт Юбары подключён, последние сообщения запрашиваются
напрямую у Telegram; без него доступны только сообщения из локальной истории.
Команда «Юбара, дэл 3» удаляет три последних сообщения Юбары в текущем чате;
ответьте «дэл» на сообщение, чтобы удалить его и команду «дэл».
Для удаления чужих сообщений в группе боту нужны права администратора
на удаление сообщений; Telegram также ограничивает удаление старых сообщений.
Можно также попросить «Юбара, удали последние 3 сообщения» или «удали последнее
сообщение» в личном чате. В группе для удаления по количеству обратитесь к Юбаре.

Для генерации отправьте `/image описание` или явно попросите нарисовать
изображение через Pollinations. Генерация доступна глобально не чаще раза
в две минуты. Изображения выдаются в чат и публикуются в настроенном
`BACKUP_CHANNEL_ID`. Одновременно выполняется только одна генерация; остальные
запросы ждут своей очереди. Для фоновых запросов боту нужны права отправки
фотографий в этот канал.
В меню перед генерацией можно настроить модель Pollinations (Flux или Turbo),
размер, негативный промпт и seed.
Настройки сохраняются отдельно для каждого чата: в группе они общие для всех
участников этой группы.

Чтобы распознать речь, ответьте на голосовое или аудиофайл фразой «Юбара, речь
в текст», «Юбара, что там говорится?» или «Юбара, что там?». Распознанный
русский текст будет отправлен в чат; используется Groq Whisper `whisper-large-v3`
и уже настроенный `GROQ_API_KEY`.

## Канал резервных копий

Создайте приватный канал и добавьте бота администратором с правами публикации,
удаления сообщений и закрепления сообщений. Узнать ID можно, добавив бота в
канал и посмотрев `channel_post.chat.id` в ответе Bot API `getUpdates` после
публикации нового поста. Запрос к Bot API выполняйте только со своим токеном
и не публикуйте ссылку с токеном. Также можно переслать пост из канала
боту, показывающему ID. Обычно ID канала выглядит как `-1001234567890`;
укажите это число в `BACKUP_CHANNEL_ID`.

Бот восстанавливает активную базу из закреплённого документа канала, а если
это невозможно — из локального `database_backup.db`. При достижении активной
базой 19 МБ история сообщений переносится в отдельный SQLite-архив; архивы
остаются локально и отправляются в канал отдельными документами. При
восстановлении архивы скачиваются по manifest из активной базы, а история
читается совместно из архива и активной БД. Резервная копия отправляется
раз в 10 минут только после изменений базы данных. В канал также отправляются
события запуска и остановки бота, а предупреждения и ошибки публикуются без
трассировок и ссылок, содержащих промпты или ключи. Служебные сообщения
Telegram о закреплении бот удаляет автоматически; для этого необходимо право
удаления сообщений.

Чтобы объединить данные из старого файла, опубликуйте в канале сообщение
ответом на нужный документ:

- `#бэкап` ответом на `database_backup.db` объединяет его с работающей базой:
  балансы суммируются, баннеры добавляются без повторов, история сообщений
  объединяется по ID чата/участника/сообщения. Текущие профили, настройки и
  совпадающие записи сохраняются. Один и тот же файл повторно не применяется.
- `#histori` ответом на архив `messages_XXXX.db` добавляет недостающие
  сообщения. Для зашифрованных сообщений необходим тот же `HISTORY_ENCRYPTION_KEY`.
  Экспорт `history_<id>.txt.enc` предназначен для чтения и не подходит для
  склейки: в нём нет ID Telegram-сообщений и участников.
- `#sessia` ответом на `telegram_session_<user_id>.session` восстанавливает
  отсутствующую сессию и оставляет её выключенной до ручной проверки. Файлы
  сессий нельзя объединить; если сессия уже существует, бот её не перезапишет.

Эти действия доступны только через настроенный `BACKUP_CHANNEL_ID`. Держите
канал приватным и добавляйте туда только доверенных администраторов: файл
Telegram-сессии даёт доступ к аккаунту. Перед объединением баз убедитесь, что
в них один и тот же `HISTORY_ENCRYPTION_KEY`.
